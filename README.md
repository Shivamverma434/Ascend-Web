# Ascend website

The public page for Ascend, served on GitHub Pages: https://shivamverma434.github.io/Ascend-Web/site/

- `site/` the website, screenshots, and the Windows and Android downloads
- `site/latest.json` the newest version; the apps read it to tell you when an update is out
- `privacy.html` the privacy policy

No personal data lives here: your data stays on your devices and in your own Google Drive.
